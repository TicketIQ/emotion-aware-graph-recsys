# Emotion-Aware Graph Recommendation System

## Problem
Traditional recommendation systems rely primarily on user–item interaction data.
They often fail to capture higher-order relationships and emotional context embedded
in content.

## Objective
This project investigates whether combining graph-based representation learning
with emotion-aware content signals can improve recommendation quality.

## Planned Approach
- Build a collaborative filtering baseline
- Extend the model using graph neural networks
- Incorporate emotion signals from movie metadata
- Evaluate using standard recommender system metrics
